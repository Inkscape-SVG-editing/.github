# Inkscape - Open Source Vector Graphics Editor

## About Inkscape

Inkscape is an open source vector graphics editor built around the SVG format. Inkscape helps designers, illustrators, cartographers, and students create scalable drawings with paths, shapes, text, gradients, and layers in one readable workspace. Inkscape vector editor sessions stay focused on precision: you draw, adjust nodes, align objects, and export clean results without fighting the tool. Inkscape SVG editing is the core workflow, so every document remains compatible with web, print, and cutting workflows.

## Key Features of Inkscape

- **Path editing** – Inkscape drawing tools let you move nodes, simplify curves, and combine shapes with boolean operations.
- **SVG compatibility** – Inkscape SVG editing keeps files readable in browsers, editors, and other vector programs.
- **Text and typography** – Add labels, titles, and captions, then convert text to paths when needed.
- **Gradients and fills** – Build smooth color transitions, patterns, and strokes for polished Inkscape illustration work.
- **Layers and objects** – Organize complex drawings with groups, layers, clones, and alignment tools.
- **Open source flexibility** – Inkscape open source development supports extensions, scripts, and community resources.

## Quick Start with Inkscape

1. **Open Inkscape** – Launch Inkscape and choose a new document or open an existing SVG file.
2. **Set the canvas** – Adjust page size, units, and grid so your Inkscape vector editor workspace matches the target output.
3. **Draw shapes** – Use rectangles, ellipses, stars, and paths to build the first version of your artwork.
4. **Edit nodes** – Switch to the node tool and refine curves with Inkscape drawing tools.
5. **Add text and color** – Place labels, apply gradients, and adjust strokes for Inkscape illustration clarity.
6. **Save and export** – Keep the SVG for future Inkscape SVG editing, then export PNG or PDF when needed.
